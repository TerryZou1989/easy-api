常见问题

数据存在哪里？会上传吗？
所有配置、参数与日志只保存在你的设备本地，不上传云端、不采集个人信息。详见隐私政策。
如何把配置迁移到新手机？
在旧设备使用「导出配置 → 复制 JSON」，通过微信等方式发给自己，在新设备「导入配置 → 从剪贴板读取」即可。
为什么请求有的 http 地址失败了？
iOS 默认限制明文（http）网络请求。如需调试局域网 http 接口，请确认已允许本地网络权限；生产环境建议使用 https。
运行时变量（如 token）会保存吗？
默认只在内存中，退出应用即清空，不会落盘、不会随配置导出。
导出的配置文件安全吗？
导出内容可能包含 token 等敏感值，分享或保管前请先检查并妥善处置。
